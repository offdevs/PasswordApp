## ✨ Features

- 🔒 **Encrypted storage** — Passwords are encrypted before being saved locally.
- 🗝️ **Secure key management** — Encryption keys are managed locally.
- 🎲 **Password generator** — Generate passwords with customizable lengths.
- 🎨 **Simple UI** — A clean and responsive user interface.
- 📴 **Local-first** — No online account required.

## 🐧 Platform Support

> [!NOTE]
> This application currently supports **Linux only**. Support for other platforms may be considered in future releases.

## ⚠️ Important Warnings

> [!CAUTION]
> **Do not manually modify, rename, or delete the application's internal files.**
>
> Changing internal files, encrypted storage, or encryption-related data may break the application or make stored passwords inaccessible.

- 💾 Keep secure backups of important data.
- 🔄 Back up your data before updating or reinstalling the application.
- 🧪 This is an early release, so bugs and unexpected behavior may still occur.

## 📦 Installation

1. Download the Linux release archive from the [Releases](../../releases) page.
2. Extract the archive.
3. Run the `passwords_application` executable.

More detailed installation instructions may be added in future releases.

## 🛡️ Disclaimer

This application is provided **as-is**, without guarantees. Use it at your own risk and maintain secure backups of important passwords.
